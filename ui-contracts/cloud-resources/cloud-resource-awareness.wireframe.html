State language

Copy that prevents cached state, credentials, and Usage from being misunderstood.
State language

0.1 Freshness

Fresh means a recent trusted read. Refreshing preserves the previous value. Stale is historical. Unavailable means no trusted value can be shown.

State language

0.2 Credentials

Each type independently uses Configured, Missing, Expired, or Needs attention. Secret values never appear.

State language

0.3 Usage Scope

Use Recorded Usage, Workspace · desk-weather, and a coverage note. Never show an unqualified Total Usage, Bill, or Balance.

Errors and recovery

Cloud uncertainty does not erase known resources or stop unrelated local work.
Recovery state

4.1 Stale Snapshot

Keep last trusted values, their original time, and a refresh-failed note. Retry later; do not present stale Live or Device connection as current fact.

Recovery state

5.1 Unavailable Without Snapshot

Show no invented resource or Usage values. Offer Retry and Continue in chat after sign-in or connectivity recovers.

Recovery summary

5.2 Remote-State Recovery

Only work that depends on confirmed remote facts is blocked. Local author, preview, build, and the open conversation remain usable.
